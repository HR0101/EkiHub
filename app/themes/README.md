# UIデザインテーマ

ページを開く・再読み込みするたびに、以下の8テーマから等確率で選びます。
固定の標準テーマや、前回選択の保存はありません。同じテーマが続く場合もあります。
「テーマ」メニューからその場で切り替えられ、Next.jsの画面内遷移では選択を維持します。
検索条件・検索結果・言語設定はテーマ切り替えで変更しません。

- Y2K / CHROME
- TERMINAL / MONO
- MOBILE / FRIENDLY
- RETRO / DESKTOP
- CLAY / TOY
- SOFT / NEUMORPHIC
- GLASS / AURORA
- VIOLET / SOFT POP

## ファイルの役割

| ファイル                          | 役割                                                         |
| --------------------------------- | ------------------------------------------------------------ |
| `app/home.css`                    | 入力・結果の配置、レスポンシブな画面構成                     |
| `app/globals.css`                 | アプリ全体の基本部品、地図、文章ページなど                   |
| `app/themes/shared.css`           | テーマ共通の操作部品、状態表示、メニューと表示サイズへの対応 |
| `app/themes/<id>.css`             | 各テーマのパレット、質感、影、角丸など                       |
| `app/themes/index.css`            | 共通CSSと各テーマの読み込み順                                |
| `src/lib/designTheme.ts`          | テーマ一覧、描画前の抽選、DOMへの適用                        |
| `src/components/ThemeToggle.tsx`  | テーマ選択メニュー                                           |
| `src/components/ThemeArtwork.tsx` | 各テーマ専用の装飾用ルートイラスト                           |

`<html data-design="glass">`のような属性で切り替えます。
描画前に`app/layout.tsx`の同期スクリプトで抽選するため、Reactの起動まで待ちません。
旧バージョンの明暗・カラー保存値は、新しいデザインの配色には使いません。
TERMINALは暗色、他は明色のフォーム・地図表示を使います。
地図の線・重心マーカーは切り替えイベントで色を読み直します。

## テーマの追加

1. `app/themes/<id>.css`に`html[data-design="<id>"]`で限定した配色と装飾を書く。
2. `app/themes/index.css`から読み込む。
3. `DESIGN_THEMES`にID・表示名・暗色かどうかを追加する。
4. `shared.css`に選択メニューの`design-preview--<id>`を追加する。
5. `npm run check`を実行し、入力・検索結果・スマホ幅で確認する。

ブランド変数を変えれば、候補リストやエラー表示などにも配色が伝わります。
配置の変更は`home.css`、共通の操作改善は`shared.css`に置き、各テーマで重複させません。

## テーマごとの表現

| テーマ     | 見出し・図案                       | 操作部品・結果表示                                         |
| ---------- | ---------------------------------- | ---------------------------------------------------------- |
| Y2K        | クロームの軌道と金属反射、斜体     | カプセル型のツール、光沢ボタン、銀色の地図枠               |
| Terminal   | 等幅の文字、直角の経路図           | 角のない端末枠、発光する数値、区切られた移動時間バー       |
| Mobile     | アプリカードの経路図、ピーチの強調 | 大きなタップ面、2列の指標タイル、穏やかな候補カード        |
| Retro      | デスクトップのタイトルバーと小窓   | ベベルの入力欄、押し込みボタン、リストビューとステータス枠 |
| Clay       | 粘土の経路、丸ゴシック             | ピーチ・ピスタチオの立体パーツ、膨らんだ指標とボタン       |
| Neumorphic | エンボスの経路盤、控えめな文字     | 沈んだ入力面・指標と浮いた操作面、柔らかな地図の額縁       |
| Glass      | 重なった透明パネル、淡いオーロラ   | 透過の階層、安定した読字面、ガラスのタイルと地図枠         |
| Violet     | コミック風のバースト、ずらした影   | ステッカーラベル、太い輪郭、押せる影、インクで区切った一覧 |

装飾イラストは読み上げ・フォーカス対象にせず、600px以下ではヘッダー右上の小さな図案へ縮小します。スマホ結果画面では隠して結果を優先します。
すべてのテーマで、未入力・エラー・選択中・無効な操作の区別は共通です。


## 構成の違い

- Y2K：上部のクロームツールバー、大きな斜体見出し、中央揃えの駅カード。
- Terminal：コンパクトな作業領域、左寄せの空状態、端末出力風の駅情報。
- Mobile：入力と結果を個別カードへ分割し、地図を独立したカードに配置。
- Retro：上部のメニューバー、ネストしたドキュメント枠、立体タブ。
- Clay：左右非対称の角丸、入力駅の接続線、ピスタチオ色の駅オブジェクト。
- Neumorphic：枠のない見出し、浮いた操作ドック、沈んだタブと情報面。
- Glass：広い透過ヘッダー、斜めの反射、内部に不透明度の高い駅カード。
- Violet：大きなポスター見出し、ステッカー状の駅情報、影で浮かせたタブ。

テーマ選択メニューでは8つの質感をサムネイルで表示します。
選択中のデザイン名はツールバーにも表示し、キーボードフォーカスは選択の輪郭とは別に示します。
