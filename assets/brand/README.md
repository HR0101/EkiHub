# ヘッダーマーク

中央の大きな駅と3つの出発駅を結ぶ図案。中央駅の内部は透明。

- `hub-mark-source.svg`: Illustratorへ読み込んだ原稿。
- `hub-mark.ai`: Illustrator 2026で保存した編集用AIマスター（PDF互換）。
- `hub-mark-export.svg`: Illustratorから保存したSVG。
- `../../public/brand/hub-mark.svg`: 上記SVGの同一コピー。CSSマスクで文字色に合わせて表示。

`src/components/PageChrome.tsx` のHeroで使用。
