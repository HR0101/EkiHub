# CDN/WAF 導入ガイド（Cloudflareを例に）

本ドキュメントでは、DDoS攻撃対策やウェブサイトのパフォーマンス向上を目的とした、Cloudflare（CDNおよびWAF）の基本的な導入手順について解説します。

## 1. 導入の目的
* **DDoS対策:** 大規模なトラフィックをCloudflareのエッジネットワークで吸収し、オリジンサーバー（実際のウェブサーバー）を保護します。
* **表示速度の向上 (CDN):** 画像やCSS、JavaScriptなどの静的ファイルを世界中のエッジサーバーにキャッシュし、ユーザーに最も近いサーバーから配信します。
* **セキュリティ向上 (WAF):** 不正なリクエスト（SQLインジェクションやXSSなど）を検知し、アプリケーションに到達する前にブロックします。

## 2. 導入の全体的な仕組み
通常、ユーザーは直接オリジンサーバーにアクセスしますが、Cloudflareを導入すると、ドメインのネームサーバー（DNS）をCloudflareに変更することで、すべての通信がCloudflareを経由するようになります。

`ユーザー -> [ Cloudflare (CDN / WAF) ] -> オリジンサーバー`

## 3. 基本的な導入手順 (Cloudflare)

### ステップ 1: アカウントの作成とドメインの追加
1. [Cloudflareの公式サイト](https://www.cloudflare.com/ja-jp/)にアクセスし、アカウントを作成します。
2. ダッシュボードから「サイトを追加」をクリックし、対象のドメイン（例: `ekihub.jp`）を入力します。
3. プランを選択します（まずは無料プラン「Free」で基本的なCDN/WAF機能が利用可能です）。

### ステップ 2: DNSレコードの確認
1. Cloudflareが自動的に現在のDNSレコード（AレコードやCNAMEなど）をスキャンします。
2. スキャン結果を確認し、抜け漏れがないかチェックします。
3. Cloudflareを経由させたいレコード（通常はウェブサイトのAレコードやCNAME）の「プロキシステータス」が**オレンジ色の雲マーク（プロキシ済み）**になっていることを確認します。

### ステップ 3: ネームサーバーの変更
1. Cloudflareから、新しいネームサーバー（例: `ns1.cloudflare.com`, `ns2.cloudflare.com`）が指定されます。
2. 現在ドメインを管理しているレジストラ（お名前.com、Xserverドメイン、Route 53など）の管理画面にログインします。
3. ドメインのネームサーバー設定を、Cloudflareから指定された2つのネームサーバーに変更します。
   *(※ ネームサーバーの浸透には数時間〜最大72時間かかる場合があります)*

### ステップ 4: SSL/TLS設定の最適化
Cloudflareとオリジンサーバー間の暗号化レベルを設定します。
* **フレキシブル:** ユーザーとCloudflare間のみ暗号化（非推奨）。
* **フル:** オリジンサーバーにもSSL証明書（自己署名可）がある場合。
* **フル (厳密):** オリジンサーバーに有効な（信頼された）SSL証明書がある場合（推奨）。

### ステップ 5: WAFとセキュリティルールの設定
1. ダッシュボードの「セキュリティ」>「WAF」に移動します。
2. 不審なアクセスに対するチャレンジ（Bot確認画面）やブロックのルールを設定できます。
3. 攻撃を受けている場合は、ダッシュボード右上の「Under Attack モード」をオンにすることで、すべての訪問者にDDoS保護のためのチャレンジ画面を表示させることができます。

## 4. 運用上の重要な注意点
* **オリジンサーバーのIPアドレスを隠す:** Cloudflareを導入しても、オリジンサーバーのIPアドレスが直接攻撃者に知られていると、Cloudflareを迂回して攻撃される可能性があります。メールサーバーのレコードなどでIPが漏れないよう注意してください。
* **IPアクセス制限（ファイアウォール）:** オリジンサーバーのファイアウォール（iptablesやAWSセキュリティグループなど）を設定し、**CloudflareのIPアドレスからのみアクセスを許可する**ように絞り込むことで、迂回攻撃を完全に防ぐことができます。
  * 参考: [Cloudflare IP Ranges](https://www.cloudflare.com/ja-jp/ips/)
* **キャッシュの管理:** アプリケーションを更新した直後など、古いファイルが配信されてしまう場合は、Cloudflareダッシュボードの「キャッシュ」からパージ（クリア）を行ってください。
